# راست‌چین هوشمند فارسی و عربی برای OpenCode

**خواندن و نوشتن فارسی و عربی در OpenCode Desktop، بدون به‌هم‌ریختن انگلیسی، مسیر فایل‌ها و کد.**

[فارسی](README.fa.md) · [English](README.md) · [العربية](README.ar.md)

> [!IMPORTANT]
> **این پروژه رسمی OpenCode نیست.** یک Patch مخصوص نسخه دسکتاپ ویندوز است که فایل `resources\app.asar` را تغییر می‌دهد. قبل از نصب، امکانات داخلی زبان عربی و RTL در OpenCode را بررسی کنید. اگر همان امکانات نیازتان را برطرف می‌کنند، این Patch ضرورتی ندارد.

## چه مشکلی را حل می‌کند؟

وقتی متن فارسی در کنار نام مدل‌ها، دستورهای ترمینال یا کد انگلیسی قرار می‌گیرد، نمایش چپ‌به‌راست می‌تواند خوانایی را خراب کند. این پروژه **جهت هر بلوک متن پشتیبانی‌شده را جداگانه تشخیص می‌دهد** و برای حروف فارسی و عربی از فونت **وزیرمتن (Vazirmatn)** استفاده می‌کند.

| نمونه | نمایش مورد انتظار |
| --- | --- |
| `این یک راهنما برای OpenCode و GitHub است.` | متن فارسی، راست‌به‌چپ |
| `هذا نص عربي مع OpenCode.` | متن عربی، راست‌به‌چپ |
| `OpenCode is an AI coding assistant.` | انگلیسی، چپ‌به‌راست |
| `C:\Projects\my-app` و کدهای برنامه | چپ‌به‌راست |

### قابلیت‌ها

- راست‌چین یا چپ‌چین‌کردن هوشمند متن گفتگو، بخش‌هایی از عنوان نشست‌ها و کادر نوشتن پیام
- حفظ خوانایی بلوک‌های کد، مسیر فایل، URL و ایمیل
- فونت محلی Vazirmatn برای حروف خط عربی، بدون جایگزینی عمدی فونت کد
- به‌روزرسانی جهت متن هنگام تایپ و نمایش تدریجی پاسخ

**محدوده:** این ابزار نه ترجمه کامل رابط OpenCode است، نه افزونه رسمی آن و نه اصلاحی برای نسخه ترمینالی (CLI/TUI).

| مورد | توضیح |

| سیستم‌عامل | ویندوز |

## نصب مرحله‌به‌مرحله

**۱.** مخزن را دانلود یا Clone کنید، فایل‌های باز را ذخیره کنید و OpenCode را کامل ببندید.

**۲.** PowerShell را در پوشه پروژه باز کنید و این دستورها را اجرا کنید:

```powershell
npm test
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

نصب‌کننده PowerShell در صورت باز بودن OpenCode متوقف می‌شود. فایل `install.bat` نیز قابل اجراست، اما **OpenCode را اجباری می‌بندد** و ممکن است کار ذخیره‌نشده از بین برود.

اگر مسیر نصب پیدا نشد:

```powershell
$env:OPENCODE_EXE = "D:\Apps\OpenCode\OpenCode.exe"
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

**۳.** OpenCode را باز کنید و متن فارسی، عربی، انگلیسی، Markdown، جدول و کادر پیام را بررسی کنید.

**۴.** برای بررسی وضعیت نصب:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\doctor.ps1
```

فایل پشتیبان و وضعیت نصب در مسیر زیر ذخیره می‌شوند:

```text
%LOCALAPPDATA%\OpenCodePersianTypography\
```

## بازگردانی نسخه اصلی

OpenCode را ببندید و اجرا کنید:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1
```

حذف‌کننده قبل از بازگردانی، هش فایل‌ها را کنترل می‌کند. اگر OpenCode آپدیت شده باشد، برای جلوگیری از جایگزینی نسخه جدید با آرشیو قدیمی عملیات را متوقف می‌کند. **Backup نسخه قدیمی را به‌زور جایگزین نکنید.**

## نکته‌های مهم درباره امنیت و آپدیت

> [!WARNING]
> این نسخه یک راهکار آزمایشی وابسته به ساختار داخلی OpenCode است؛ قبل از استفاده روزمره، روی همان نسخه نصب‌شده تست شود.

- آپدیت رسمی OpenCode ممکن است Patch را حذف کند یا Selectorهای داخلی را تغییر دهد.
- نصب‌کننده فعلی هنوز تعویض اتمیک آرشیو و حفظ کامل فایل‌های unpacked را تضمین نمی‌کند؛ احتمال اختلال در اجرای برنامه روی برخی بیلدها وجود دارد.
- تست‌های خودکار فعلی، نصب/حذف واقعی ویندوز و سازگاری بصری همه صفحات را پوشش نمی‌دهند.
- فایل JavaScript و فونت محلی‌اند، اما ابزار بسته‌بندی ممکن است از npm دریافت شود و نسخه آن فعلاً قفل نشده است.
- فایل اجرایی `OpenCode.exe`، چت‌ها و تنظیمات عمداً تغییر داده نمی‌شوند؛ ولی **فایل داخلی برنامه** اصلاح می‌شود.

### آیا OpenCode خودش RTL ندارد؟

OpenCode در نسخه‌های جدید، از جمله 2.1.4، برای زبان عربی و چیدمان راست‌به‌چپ امکاناتی دارد؛ بااین‌حال پشتیبانی کامل از متن ترکیبی داخل گفتگو همچنان موضوع [درخواست رسمی RTL](https://github.com/anomalyco/opencode/issues/26915) است. **اول از قابلیت داخلی استفاده کنید**؛ این پروژه برای نیازهای برطرف‌نشده طراحی شده است.

## رفع اشکال

| مشکل | اقدام مناسب |
| --- | --- |
| برنامه پیدا نمی‌شود | متغیر `OPENCODE_EXE` را تنظیم کنید |
| خطای `OpenCode renderer changed` | نصب را متوقف کنید؛ بررسی سازگاری را دور نزنید |
| پس از آپدیت Patch غیرفعال شده | سازگاری نسخه جدید را قبل از نصب مجدد بررسی کنید |
| بازگردانی نسخه اصلی رد می‌شود | از Repair یا نصب مجدد نسخه رسمی سازگار استفاده کنید؛ Backup قدیمی را تحمیل نکنید |
