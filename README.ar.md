# دعم الكتابة العربية والفارسية من اليمين إلى اليسار في OpenCode

**محادثات عربية وفارسية أوضح في OpenCode Desktop، مع الحفاظ على ترتيب النصوص الإنجليزية والشيفرة البرمجية والمسارات.**

[العربية](README.ar.md) · [فارسی](README.fa.md) · [English](README.md)

> [!IMPORTANT]
> **هذا مشروع مجتمعي غير رسمي، وليس إضافة أصلية من OpenCode.** تُعدّل أداة التثبيت ملف `resources\app.asar` في تطبيق سطح المكتب على Windows. تحقّق أولاً من خيارات اللغة العربية واتجاه RTL المدمجة في OpenCode؛ لا حاجة إلى هذه الأداة إذا كانت تفي بالغرض.

## لماذا قد تحتاج إليه؟

في المحادثات البرمجية، تختلط الجمل العربية والفارسية بأسماء الأدوات والأوامر والمسارات الإنجليزية. وقد يؤدي عرضها كلها باتجاه واحد إلى ارتباك ترتيب الكلمات وعلامات الترقيم.

تحدّد هذه الأداة **اتجاه كل كتلة نصية مدعومة على حدة**، وتستخدم خط **Vazirmatn** لتحسين عرض الحروف العربية والفارسية.

| مثال | الاتجاه المتوقع |
| --- | --- |
| `هذا شرح لإعداد GitHub مع OpenCode.` | من اليمين إلى اليسار |
| `این راهنمای فارسی OpenCode است.` | من اليمين إلى اليسار |
| `OpenCode helps with coding tasks.` | من اليسار إلى اليمين |
| `C:\Projects\demo` ومقاطع الشيفرة | من اليسار إلى اليمين |

### ما الذي توفره؟

- تحديد اتجاه نصوص المحادثة وأجزاء من عناوين الجلسات وعلامات التبويب ومحرّر الرسائل.
- إبقاء مقاطع الشيفرة وعناوين URL والبريد الإلكتروني ومسارات الملفات باتجاه LTR.
- عرض الحروف العربية والفارسية بخط Vazirmatn المضمّن محلياً.
- إعادة حساب الاتجاه أثناء الكتابة وتدفّق إجابات المساعد.

**حدود الأداة:** لا تترجم واجهة OpenCode بالكامل، ولا تغيّر إجابات النموذج، ولا تدعم واجهة الطرفية CLI/TUI.

## المتطلبات والتوافق

| المتطلب | التفاصيل |
| --- | --- |
| النظام | Windows |
| التطبيق | **OpenCode Desktop (Electron)** |
| الإصدار المستهدف | **2.1.4**؛ لا يوجد ضمان للتوافق مع الإصدارات اللاحقة |
| أدوات التثبيت | Node.js 18 أو أحدث، مع npm/npx |
| الاتصال بالإنترنت | قد يستخدم `npx` الشبكة لتنزيل `@electron/asar` |

## التثبيت

**١.** نزّل المستودع أو استنسخه، واحفظ عملك، ثم أغلق جميع نوافذ OpenCode.

**٢.** افتح PowerShell داخل مجلد المشروع ونفّذ:

```powershell
npm test
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

يرفض مثبت PowerShell العمل إذا كان OpenCode قيد التشغيل. ويمكن استخدام `install.bat`، لكنه **يغلق OpenCode بالقوة** وقد يؤدي إلى فقدان التغييرات غير المحفوظة.

إذا لم يعثر المثبت على البرنامج، حدّد المسار:

```powershell
$env:OPENCODE_EXE = "D:\Apps\OpenCode\OpenCode.exe"
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

**٣.** أعد تشغيل OpenCode واختبر المحادثات العربية والفارسية والنصوص الإنجليزية والجداول والشيفرة ومحرّر الرسائل.

**٤.** تحقّق من حالة التثبيت:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\doctor.ps1
```

تُحفَظ النسخة الاحتياطية ومعلومات التثبيت في:

```text
%LOCALAPPDATA%\OpenCodePersianTypography\
```

## إزالة التعديل واستعادة النسخة الأصلية

أغلق OpenCode ثم نفّذ:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1
```

يتحقق برنامج الإزالة من بصمات SHA-256 المسجلة قبل الاستعادة. إذا تغيّرت ملفات OpenCode بعد تحديثه، يتوقف بدلاً من استبدال إصدار جديد بنسخة قديمة. **لا تفرض استعادة أرشيف يعود إلى إصدار مختلف.**

## الأمان والتحديثات والقيود

> [!WARNING]
> هذا تعديل مرتبط ببنية داخلية غير مستقرة في OpenCode، وليس بديلاً رسمياً طويل الأمد. اختبره على إصدارك الفعلي قبل الاعتماد عليه.

- قد تزيل تحديثات OpenCode التعديل أو تغيّر محددات عناصر الواجهة التي يعتمد عليها.
- لا يضمن المثبّت الحالي استبدال الأرشيف بصورة ذرّية أو الحفاظ الكامل على الملفات غير المضغوطة (`app.asar.unpacked`). وقد يتأثر تشغيل بعض الإصدارات.
- الاختبارات الآلية الحالية تتحقق من بعض وظائف JavaScript ومن بنية الملفات، ولا تمثل اختبار تثبيت واستعادة وتوافق بصري شاملاً على Windows.
- ملفات الخط ووقت التشغيل محلية؛ مع ذلك قد يقوم `npx` بتنزيل أداة الحزم، ولم يُثبَّت إصدارها بعد.
- لا تُعدّل الأداة عمداً ملف `OpenCode.exe` أو المحادثات أو الإعدادات، لكنها تغيّر أرشيف التطبيق الداخلي.

### أليس لدى OpenCode دعم RTL أصلاً؟

تتضمن الإصدارات الحديثة من OpenCode، ومنها 2.1.4، دعماً للغة العربية واتجاه واجهتها. لكن عرض النصوص المختلطة داخل المحادثات لا يزال موضوع [طلب الدعم الرسمي للغات RTL](https://github.com/anomalyco/opencode/issues/26915). **استخدم الميزة الأصلية أولاً**، ثم قيّم هذا التعديل فقط إذا بقيت مشكلة واضحة.

## حل المشكلات

| المشكلة | الإجراء |
| --- | --- |
| تعذّر العثور على OpenCode | عيّن المتغير `OPENCODE_EXE` إلى المسار الصحيح |

| اختفاء التعديل بعد التحديث | تحقّق من التوافق قبل إعادة التثبيت |
| رفض الاستعادة | استخدم إصلاح التطبيق الرسمي أو إعادة تثبيته؛ لا تفرض أرشيفاً قديماً |
